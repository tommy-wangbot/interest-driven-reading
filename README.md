# 兴趣驱动的信息筛选

让 AI 筛信息之前，先告诉它你正在回答什么问题。

这里分享一套个人实践方法：把研究问题写成明确的证据需求和排除项，再据此选择来源、筛选内容、安排收藏去向。适合想让信息阅读服务于具体工作或研究的人。

## 从一个问题开始

1. 读[《先写清你在追什么》](docs/先写清你在追什么.md)，了解这套方法的来由与边界。
2. 复制[研究关注清单模板](templates/research-focus.md)，只填一个当前问题，同时写清清单适用于哪些内容。
3. 参考[虚构填写示例](examples/research-focus-example.md)，拿几条材料试筛：保留的材料准备怎么用？暂不看的理由是否成立？
4. 遇到漏掉的好材料或误收的内容，改清单，再试一轮。

清单帮助表达当前的信息需求。日常兴趣、偶然发现和纯粹好奇，可以留在清单适用范围之外。

## 当前公开范围

本仓库提供方法文章、可填写模板和教学示例。完整自用系统尚未公开；这里没有可以直接安装运行的信息订阅工具，也没有足够证据证明这套方法已经提高推荐效果。

你可以独立使用这些材料，不必等待后续代码。本仓库不承诺固定更新频率或个人部署支持。
